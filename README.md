# Fauna Focus
A platform where nature lovers share their unique experiences with the wild. Here, users can submit captivating photos of natural landscapes and wildlife, showcasing the beauty of our planet. Additionally, a logged-in user can post detailed 'Experiences', which are personal stories that describe encounters with animals in their natural habitats. 

## You Will Be Able To:

1. Create a profile
2. Submit posts that allow you to include a photo
3. Submit stories (experiences) about encounters with wildlife
4. Search between the two based on the logged-in user and category (such as mammal or amphibian)
5. Have basic CRUD abilities
6. As well as have the option of editing/deleting others submitted posts if you have admin status
